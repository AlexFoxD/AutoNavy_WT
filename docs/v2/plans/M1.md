# M1 implementation plan

Scope: ARCH-01, CFG-01, CLI-01, APP-01 startup boundary and finite replay only. Live capture, recognition, input, and telemetry are delivered by later milestones. No legacy execution fallback is permitted.

## Contracts and decisions

- `load_settings(path: str | Path | None = None, overrides: Mapping[str, object] | None = None) -> Settings`. Explicit files merge over immutable built-in dataclass defaults; nested explicit overrides merge last. Unknown sections/keys and wrong types fail with `ConfigurationError(ValueError)`. Relative resource paths resolve from the distribution root, independent of cwd; config filenames themselves are caller paths. No environment configuration layer.
- `Settings` contains frozen capture, geometry, vision, telemetry, input, control, runtime, diagnostics, and paths dataclasses plus schema_version. Configure all milestone domains now. A TOML `enable_input` value alone never authorizes physical input: CLI requires the opt-in switch. Replay always rejects enable_input. Default capture is DXcam; replay requires an explicit fixture.
- Rectangles are `(left, top, right, bottom)` in frame pixels. Default profile is legacy 1280x720 at UI scale 1.0; resource root is derived from package location (executable directory when compiled). Validate ROI and content bounds before startup. Runtime output locations default to ignored logs, not tracked assets.
- `FramePacket(image, pixel_format, publication_id, source_generation, received_at_ns, geometry_id, source_timestamp=None, source_clock=None, source_sequence=None)` owns a copied, read-only uint8 NumPy image. Optional source time requires a clock domain. A publication is not proof of a unique game presentation. No source timestamps are invented.
- `RuntimeState(str, Enum)` exposes stopped, starting, waiting, queueing, in_battle, recovering, paused, error, stopping.
- `ReplayCapture(fixture: str | Path, *, max_frames: int | None = None)` reads a strict schema-v1 manifest of explicit synthetic colors/dimensions, no URLs/devices. `start()`, `read() -> FramePacket | None`, `stop()`, `close()`; EOF returns None and remains exhausted. Restart increments generation and retains publication ordering. No implicit looping; max_frames caps a finite manifest sequence.
- `Application(settings: Settings).run() -> int`, `.stop() -> None`, `.close() -> None`; state/frames_processed/last_frame expose finite progress. Replay completes with 0; deliberate stop/Ctrl+C with 0; invalid config with 2 through CLI; unavailable live backend/runtime errors with 3. Cleanup occurs in finally; stop/close are idempotent. Replay never constructs telemetry/input.
- `main(argv: list[str] | None = None) -> int` is shared by package, root autonavy.py, start_prog.py and main.py. Help returns 0; parser errors return 2. `--run` is accepted as a compatibility flag and grants no input permission. Legacy skip1/skip2/skip3 sentinels are retired. Full explicit preflight is retained through the existing safe diagnostic implementation; M8 migrates packaging/scripts.
- Preserve injected `autonavy.run_application(application_loader=..., output=print, log_path=None) -> int` behavior and existing Russian compatibility failure text only. New CLI/application messages are English.
