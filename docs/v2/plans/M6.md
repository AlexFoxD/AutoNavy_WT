# M6 navigation and controllers implementation plan

> **For agentic workers:** Execute inline with Superpowers executing-plans and TDD; the coordinator owns review. No additional production writers.

**Goal:** Wire ordered native routes and independent PID states into the actual battle policy, with bounded native-worker cleanup.

**Architecture:** Immutable normalized route/cursor values preserve topology. A lazy native adapter validates the goal-to-origin interior protocol and keeps legacy tactical-image preprocessing. A single owned supervisor manages one isolated native process, a latest-request slot, bounded attempts/backoff and stale-result rejection. Battle navigation consumes current M4 snapshot/map bytes and emits M5 typed intents.

**Tech stack:** Existing CPython 3.11 x64, NumPy/OpenCV, bundled JPS extension, standard-library multiprocessing/threading/dataclasses, pytest.

**Spec:** docs/v2/SPEC.md NAV-01, CTRL-01; .superpowers/sdd/PLAN/task-6-brief.md including appended contracts; docs/v2/AUDIT.md and evidence/M5.md.
