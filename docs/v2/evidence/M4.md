## API integration guide for M5 and M6

`Application(settings, *, telemetry=None, clock_ns=time.monotonic_ns)` constructs only inert Python service state. Default replay gets OfflineTelemetry (no Requests import/construction); DXcam/OBS get TelemetryService. All template validation and successful capture startup precede telemetry.start(). Explicit offline replay injection is available for M5 fixtures. The caller owns the offline nature of an explicitly injected source. Existing subprocess guards prohibit Requests import as well as socket connection for every supported import/config/replay entrypoint.

`TelemetryService(settings.telemetry, *, session_factory=None, clock_ns=..., join_timeout_s=2.0, fault_interval_s=5.0)` owns one daemon thread and exactly one Session constructed/used/closed inside that worker. Production disables environment proxy inheritance and redirects. `start()` is idempotent; pre-start request_stop() latches cancellation without constructing a Session. `request_stop()` only signals. `close()` marks terminal before a bounded join, is repeatable, reports a still-live worker or Session cleanup exception, and never races Session.close against in-flight IO. It intentionally does not restart; create a new service for a new application lifecycle.

Objects use /map_obj.json; metadata uses /map_info.json; image uses the preserved /map.img?gen=2 endpoint. Target object rate defaults to 10 Hz; a serial worker performs the next poll after the current cycle, never queues a missed tick. Metadata/image work can lower observed object rate. Default connect/read timeout is (0.5,0.5); failure backoff uses stop-event waits, starts .5 seconds and caps at 5 seconds. Diagnostics are bounded to one telemetry fault per configured interval, including changing faults.

`service.snapshot()` returns a frozen TelemetrySnapshot. Fields: generation, player, enemies, zones, metadata, received_at_ns, valid, error, object_ttl_ns and metadata_ttl_ns. Player exposes normalized `(x,y)` position plus dx/dy; Enemy exposes position. Zone positions are immutable tuples. Metadata exposes map_min/map_max/grid_steps, its own received_at_ns, key and scale (x extent). Snapshot.valid requires successful validated objects, exactly one Player with nonzero finite direction, fresh objects, and fresh valid metadata. Missing Player clears all actionable fields; successful parsing still advances the object receive time. Failed HTTP/status/schema polls preserve the previous successful object receive time and immediately remove player/enemies/zones. Error text is bounded. Image failure is independent and never refreshes objects or makes enemies actionable.

Default object TTL is 1 second and metadata TTL is 30 seconds; equality to the TTL is stale. Consumers use a newly obtained service.snapshot() for a decision. If retaining a snapshot, call `.at(now_monotonic_ns)` immediately before use; `.valid` on a retained value is not a perpetual permission. This removes stale player/enemies/zones and stale metadata without altering successful receive times. Application stores the last observed service snapshot each loop/after vision; `app.last_snapshot` reevaluates its TTL at access and removes actionable fields after application stop. M5 dispatch should additionally take current service/stop/generation/focus prerequisites immediately before actuation; retained historical snapshots cannot learn about a later failed poll by themselves.

Generation is locally inferred, NOT a server battle/session ID. It starts at zero, increments when valid metadata first establishes an identity or its (map_min,map_max,grid_steps) key differs, increments on successful object recovery after a failure/missing Player/unavailable metadata if that cycle has not already changed identity, and increments when the interval since the preceding successful object receive crosses object TTL, including a slow in-flight request. Metadata is revalidated on recovery/staleness; observing invalid metadata removes the cached metadata and image. Generation changes clear the image and force its refresh. A missing Player can cause conservative repeated generation increments during continued absence. M5 should cancel pending actions/reset controllers on generation changes. No endpoint in the audited protocol proves battle identity; two sessions with identical map bounds and no observed interruption cannot be reliably distinguished. Metadata refresh can only detect a map-key change when its request runs, and separate HTTP endpoints do not provide an atomic server snapshot.

Hostile classification is centrally conservative: only literal icon Ship with RGB [250,12,0] or [240,12,0]. Unknown icons and merely red hue/ground_model do not become hostile. Player literal remains Player; zones are capture_zone with well-formed RGB excluding exact blue [23,77,255]. Known actionable objects require finite normalized positions; duplicate Player, malformed known color/vector, nonfinite numbers, zero heading, invalid map validity/schema and nonpositive/overflowed dimensions invalidate data. Original protocol strings/assets are preserved.

`service.map_image()` returns None or frozen MapImage(data: bytes, key, generation, received_at_ns). It is one encoded PNG/JPEG in memory, capped at 8 MiB, with verified and decoded dimensions <=16,777,216 pixels. JSON bodies are capped at 1 MiB and object lists at 10,000. Image timestamp and 30-second TTL are independent of object receipt; image availability also requires matching current generation/map key and fresh metadata. No output path is written. M6 can decode `image.data` in memory to BGR via OpenCV; use normalized x/y positions against actual decoded width/height and metadata key, not a presumed 128x128 image or a stale src/origin_map.png. The cache retains encoded bytes only; bounded decoded memory is transient validation work.

`info(source).update()` projects current snapshot data into copied legacy-shaped player/mapinfo/enemy values, sorting distances using the preserved x scale. `toolkit.map.get_point(onlyplayer=False, *, source)` returns legacy-shaped copied lists; player-only unavailability is ([], None), full unavailability is ([], [], []). `download_map(*, source)` returns cached encoded bytes or None; it no longer downloads or writes a file. No-argument old navigation callers are intentionally unsupported until M6 migrates them; they are outside the supported Application path and cannot silently revive HTTP. Explicit diagnostic runtime_preflight API probe remains separate from control and unchanged for M8.

## Cleanup and limits

Application signals both services, then attempts capture and telemetry cleanup independently, aggregating every cleanup error. Concurrent close callers share completion and the same aggregate failure. Their budget is capture.stop_timeout_s + 2 * runtime.join_timeout_s, accounting for the telemetry join and prior runtime allowance. All existing M2 close/start/generation/cancellation and shared-close tests passed unchanged except explicit OfflineTelemetry injection. M5 must put input neutralization before these potentially waiting cleanups; this milestone adds no physical input.

Requests tuple timeout is not a total end-to-end deadline. Event cancellation wakes polling backoff but cannot interrupt arbitrary socket/native decode calls. A worker that does not return within join allowance remains a daemon with its Session; close reports the failure honestly. When the operation eventually returns, the worker drops late objects/images and closes its Session. No cross-thread close, asynchronous exception injection, process-kill claim, or fabricated bounded socket guarantee is used. Bounded byte/dimension limits constrain memory, not arbitrary native-call duration.

Self-review checked lifecycle races, late stopped publication, per-component receive times and TTL, recovery/session identity, default live selection/replay isolation, derived finite values, map decode and source preservation, and compatibility caller removal. No real-battle protocol capture, live recognition/navigation calibration, achieved polling rate, game input, or arbitrary socket shutdown guarantee is claimed.
