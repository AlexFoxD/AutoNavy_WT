## Exact shared API contracts

- `autonavy.config.ConfigurationError(ValueError)`.
- `resource_root() -> pathlib.Path`.
- `load_settings(path: str | Path | None = None, overrides: Mapping[str, object] | None = None) -> Settings`.
- `validate_settings(settings: Settings) -> Settings`: checks directly built dataclasses too and returns settings with resolved resource paths.
- `Settings(schema_version=1, capture=CaptureSettings(), geometry=GeometrySettings(), vision=VisionSettings(), telemetry=TelemetrySettings(), input=InputSettings(), control=ControlSettings(), runtime=RuntimeSettings(), diagnostics=DiagnosticsSettings(), paths=PathSettings())`; nested values use default factories. Full fields/defaults live in `autonavy/config.py` and `configs/default.toml`.
- Capture fields: `backend: str='dxcam'`, `device_index: int=0`, `output_index: int=0`, `pixel_format: str='BGR'`, `fps: int=60`, `repeated_frames: bool=False`, `obs_api: str='auto'`, `width: int=1280`, `height: int=720`, `read_failure_limit: int=3`, `startup_timeout_s: float=10.0`, `stop_timeout_s: float=2.0`, `frame_timeout_s: float=1.0`, `fixture: Path | None=None`, `max_frames: int | None=None`.
- `FramePacket(image: numpy.ndarray, pixel_format: str, publication_id: int, source_generation: int, received_at_ns: int, geometry_id: str, source_timestamp: float | None=None, source_clock: str | None=None, source_sequence: int | None=None)`. Frozen structure; image is an owned contiguous read-only copy. BGR/BGRA uint8 accepted; empty/wrong-type/wrong-channel images rejected. Optional source timestamp and clock domain must be paired. Publication identity is `(source_generation, publication_id)`; replay publication_id additionally increases across restarts. A publication does not claim a unique rendered presentation.
- `RuntimeState(str, Enum)`: STOPPED, STARTING, WAITING, QUEUEING, IN_BATTLE, RECOVERING, PAUSED, ERROR, STOPPING (lowercase values).
- `ReplayCapture(fixture: str | Path, *, max_frames: int | None=None)`. `start() -> None`, `read() -> FramePacket | None`, `stop() -> None`, `close() -> None`. `closed`, `started`, `source_generation`, `publication_id` are observable. Idempotent start while running; stop permits restart with a new generation; close is terminal/idempotent. EOF remains EOF until explicit stop/start. No looping option. Manifest size/frame allocation/frame-count bounds are validated.
- `Application(settings: Settings)`. `run() -> int`, `stop() -> None`, `close() -> None`; state, frames_processed, last_frame, last_error, capture, stop_event are available for later runtime integration. A stopped-before-run app performs no acquisition. Normal EOF/stop/Ctrl+C returns 0; runtime/startup/cleanup errors return 3 and retain ERROR state. Application instances are single-use and closed in finally.
- `main(argv: list[str] | None=None) -> int`: help/check-config/finite replay return 0, parameter/config errors 2, startup/runtime failure 3. Does not raise SystemExit to callers. Script guards raise SystemExit(main()).
- `run_application(application_loader=load_application_main, output=print, log_path: Path | None=None) -> int`: preserves injected loader/error log compatibility; now also propagates an integer application result.

Manifest v1 requires exactly schema_version=1, synthetic=true, pixel_format, geometry_id, width, height, and frames. Each frame has exactly `color`, a uint8 channel list. No file/image/URL loading or source timestamps are invented. The smoke fixture is not gameplay accuracy evidence.
