Completed keys do not rebuild each tick; max configured attempts with interruptible backoff; latest serial rejects superseded results. - NativeJob owns a spawn-context child and fixed shared route buffer (65,536 pairs of doubles =1MiB), count and512-byte error field. Parent reads only after child exit; no pipe send/recv deadlock or unbounded queue. Stop/supersession/timeout terminate and reap, use kill fallback within configured total join allowance, close Process OS handles. Failure to reclaim is fatal and prevents another spawn.
